A working system with no readable documentation is a hostage situation waiting to happen — the day the one person who understands it leaves. Handover isn't complete when the code runs; it's complete when someone on your team can change it from the written word alone. Written plainly, for the people who'll actually run it, not for the engineers who built it. That document is the difference between a capability you keep and one that quietly walks out the door.
