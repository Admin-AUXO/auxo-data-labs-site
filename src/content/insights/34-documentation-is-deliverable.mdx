A working system with no readable documentation is a hostage situation on a delay timer — armed the day the one person who understands it takes a better offer. Handover isn't done when the code runs; it's done when someone on your team can change it from the written word alone. Write it plainly, for the people who'll actually operate it, not for the engineers who built it and have already moved on to the next thing. That document is the whole difference between a capability you keep and one that quietly walks out the door with its laptop.
