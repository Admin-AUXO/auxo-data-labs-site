The first thing you automate shouldn't be the thing that can't be undone. Start where being wrong is cheap: drafting, sorting, matching, routine reports. Let a track record build before an agent touches anything that bites back. OpenAI's own guide to building agents says sensitive, irreversible or high-stakes actions, such as refunds or payments, should go to a person until the agent has proved reliable. By the time you reach the work that matters, the system has earned some trust. Ambition is fine. Sequence it.

Where this fits: [Build](/how-it-works/). Agents start on routine work, and a person approves what goes out.
