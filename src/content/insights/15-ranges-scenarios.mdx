A single forecast line tells you what someone hopes will happen. A base case, a downside, and a note on what would have to be true for each tells you what to do if it doesn't. Scenario analysis is now an expectation, not a flourish — IFRS S2 asks issuers to test resilience against more than one climate pathway. The same discipline serves any forecast, because it answers the only question that matters at the point of commitment: what breaks this, and how would we see it coming?

Where this fits: [clear reporting](/services/) — forecasts that show the range and the assumptions behind it.
